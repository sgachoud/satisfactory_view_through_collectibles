First public beta of View Through Collectibles.

- Configurable outlines for hard-drive pods, power slugs, Mercer Spheres, Somersloops, collectible flora and dropped items.
- Optional local map dots at scale 1.0, with compass icons shown only while highlighted.
- Collected-state filtering shared by map dots and world indicators.
- Solo discovery and optional multiplayer server support using each client's settings.
- Loaded-object fallback when the remote server does not have the mod.
- Windows Steam/Epic clients and Windows/Linux dedicated-server packages.
